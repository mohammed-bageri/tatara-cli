# Step 4 — `@tatara/auth` + `@tatara/keycloak`

**Goal:** Move the auth plumbing into packages. The app keeps its own `betterAuth({...})` and short wiring files.

**Spec:** `docs/superpowers/specs/2026-10-30-framework-packages-design.md` (Packages rows `@tatara/auth`, `@tatara/keycloak`).

## Package API

| Package | Export | What |
|---|---|---|
| `@tatara/auth` | `Principal`, `AuthEnv`, `principalMiddleware(resolvers)`, `PrincipalResolver` | sets `c.var.principal` from the first resolver that matches |
| | `sessionPrincipal(auth, headers)` | better-auth session → principal (drops an org the user left) |
| | `requireAuth()`, `requireRole(...roles)`, `currentPrincipal(c)` | guards, as before |
| | `mergeAuthOpenApi(document, auth, basePath)` | better-auth's endpoints in the app's OpenAPI document |
| | `createOutbox({ enabled, limit? })`, `SmsSender`, `consoleSmsSender(logger)` | dev outbox and the SMS seam |
| `@tatara/auth/testing` | `createTestUser(auth, user)`, `sessionHeaders(auth, userId)` | real users and sessions, no HTTP |
| `@tatara/keycloak` | `keycloakVerifier({ url, realm, audience })` | JWKS verification; `useKeys()` for tests |
| | `keycloakTokens({ verifier, logger, organizations? })` | the better-auth plugin, as before |
| | `keycloakPrincipal(auth, authorization)`, `rolesOf`, `organizationOf` | principal resolver and claim helpers |
| `@tatara/keycloak/testing` | `useTestKeys(verifier)` | a signer for tokens the verifier accepts |

The functions take the app's `auth` instance through small structural types, so nothing reads app config.

## What the app keeps

- `auth.ts`: the app's `betterAuth({...})`.
- `principal.ts`: `principalMiddleware<AppEnv>([sessionPrincipal…, /* slot resolvers */])`.
- `delivery.ts`: `outbox = createOutbox(...)`, plus `deliverEmail` and `deliverSms`.
- `sms.ts`: `smsSender`.
- `keycloak.ts`: `keycloak = keycloakVerifier(...)`.
- `tests/helpers/auth.ts`: `asUser` and `authenticate` with their slots.

## Codemod 0.5.0 `auth-package`

The files that must change together are moved as a group, and each group moves only if every file in it is unchanged and no outside file imports a name that goes away. The groups are:

- OpenAPI + outbox: `app.ts`, `delivery.ts`, and the removed `openapi.ts`.
- `sms.ts`.
- `principal.ts`.
- Test helpers.
- Keycloak: `auth.ts`, `keycloak.ts`, the token command, the token test, the test helpers, and the removed `keycloak-plugin.ts`.

`middleware.ts` is removed when unchanged, and its imports are rewritten to `@tatara/auth`.
